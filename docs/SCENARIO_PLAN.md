## 시나리오 문서 구성 표준 (각 파일 필수 섹션)

각 `docs/scenarios/{id}.md` 파일은 아래 8개 섹션을 반드시 포함한다.

```
1. 메타 정보      — ID, 제목, 장르, 난이도, 인원, 예상 소요 시간
2. 배경 설정      — 장소, 시간대, 피해자 프로필
3. 등장인물       — 피해자 + 용의자 3명 (각각 동기 보유)
4. 범죄 현장 카드  — scene.jpg 묘사 (플레이어가 보는 첫 장면)
5. 단서 카드 10장 — 라벨 / 내용 / 제공 정보 / 게임 연결 구조
6. 경고 카드      — 힌트 내용 (정답 직접 노출 금지, 방향만)
7. 단서 발견 스텝  — 추천 공개 순서 + 각 단계 논리 흐름
8. 정답           — 용의자/수단/동기 + 키워드 배열
```

## 단서 설계 원칙

### 논리 흐름 구조 (10장 기준)
```
단서 01~03  — 현장 물리적 증거 (사망 방식·시각·현장 상태)
단서 04~06  — 인물 관계·알리바이 (용의자 좁히기)
단서 07~08  — 핵심 증거 (범인 특정 가능한 직접 단서)
단서 09~10  — 동기 증거 (왜 했는가, 이익 관계)
경고 카드   — 막혔을 때 힌트 (핵심 단서 09~10을 가리킴)
```

### 단서 검증 기준 (3회 체크)
- **V1 일관성**: 10장 단서가 서로 모순 없이 하나의 정답을 지지하는가
- **V2 추리 가능성**: 정답 모르는 플레이어가 10장만으로 정답 도달 가능한가
- **V3 키워드**: answer.keywords가 일반적인 답변 패턴을 충분히 커버하는가

## 신규 시나리오 3개 개요

### s1e07 — The Last Masterpiece (마지막 걸작)
- 피해자: 파올로 만치니 (72세, 은퇴한 화가)
- 장소: 베네치아 아틀리에 (잠긴 내실)
- 사망: 독 묻은 붓, 수십 년간 쌓인 납 안료 접촉사 위장
- 범인: 아들 루카 (유산 탈취)
- 수단: 납 화합물 (초산납) 만성 중독 유발
- 동기: 거액의 위작 판매 수익 독점

### sp02 — Murder on New Year's Eve (새해 전야의 살인)
- 피해자: 클라우디오 리치 (50세, 투자자)
- 장소: 밀라노 31층 옥상 파티
- 사망: 추락사 (난간 의도적 약화 + 술 탄 음료)
- 범인: 사업 파트너 미켈레 (파산 직전 공동 투자금 독점)
- 수단: 만취 유도 후 추락 (펜스 볼트 사전 제거)
- 동기: 7백만 유로 공동 투자금 독점 상속

### sp03 — The Wedding Crash (결혼식의 참사)
- 피해자: 프란체스코 살라 (45세, 신랑 아버지)
- 장소: 시칠리아 빌라 결혼식장
- 사망: 케이크 내 알레르기 유발 물질 (땅콩 오일)
- 범인: 신부 어머니 지나 (과거 원한)
- 수단: 견과류 알레르기 유발 (에피펜 숨김)
- 동기: 20년 전 사업 배신으로 인한 원한
