  → 에밀리오도 카드키 있고 원한 있음 = 혼선.

  → 22:40~23:00 후문 경비 공백 = 다리오 반출 가능 시간.

STEP 5: 단서 09 (CCTV 차량)
  → 22:55 후문 SUV = 다리오 차량 (번호판 RM-48 교차 확인).

STEP 6: 단서 02 (업무 일정)
  → 안나-다리오 계약 분쟁 중 = 갈등 관계.

  → 다리오 미술품 밀수 의혹 + 안나 세관 제보 예정 = 동기 완성.

STEP 9: 단서 07 (이메일)
  → 안나가 내일 다리오를 제보할 예정이었다 = 폭행 동기 확정.
