## 4. 범죄 현장 카드 (scene.jpg 묘사)

옥상 테라스 난간 구역. 난간 패널 하나가 기울어진 채 고정되어 있음 (볼트 1개만 남음). 패널 하단부에 최근 공구 사용 흔적. 테라스 바닥에 샴페인 잔 깨진 조각. 옥상 한편에 음료 테이블, 사용된 잔 다수. 클라우디오의 재킷이 난간 근처 벤치에 놓여 있음.

**플레이어 포인트:**
- 난간 볼트 1개 (사전 제거)
- 공구 흔적 (최근)
- 재킷 (떨어지기 전에 벗었다 = 의식 있었나)

## 7. 단서 발견 스텝

```
STEP 1: 단서 02 (난간 감정)
  → 볼트 의도적 제거 = 타살 확정.

STEP 2: 단서 01 (부검)
  → 혈중 알코올 0.24% = 만취 상태 (자연히 만취 vs 유도).

STEP 3: 단서 03 (음료 감정)
  → 잔 내 알코올 강화 = 의도적 만취 유도.

STEP 4: 단서 04 (미켈레 동선)
  → 미켈레가 음료 관리 + 잔 직접 건넴 = 투여자.

STEP 5: 단서 07 (프란체스카 진술)
  → 11:45까지 다퉜고 알리바이 확인 → 배제.

STEP 6: 단서 08 (다비데 진술)
  → 11:02 퇴장 확인 → 배제.

STEP 7: 단서 06 (클라우디오 이메일)
  → 내일 감사 예정 = 미켈레 위기.

STEP 8: 단서 05 (펀드 기록)
  → 5.2백만 횡령 = 들킬 상황.

STEP 9: 단서 09 (미켈레 재정)
  → 카지노 부채로 횡령 동기 구체화.

STEP 10: 단서 10 (엘리베이터 CCTV)
  → 전날 오후 미켈레 공구 가방 옥상 방문 = 사전 난간 조작 확정.
```
